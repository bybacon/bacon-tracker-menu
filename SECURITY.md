# Security Policy

BaconTrackerMenu starts a local bacon-tracker server bound to `localhost` and opens it in your browser. It makes no other network connections.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems. Email **alex@aberger.me** with a description, steps to reproduce, and your macOS and app versions. Server-side issues belong to [bacon-tracker](https://github.com/bybacon/bacon-tracker/blob/main/SECURITY.md).

## Supported versions

Security fixes land in the latest 1.x release.
